Зелёные тесты сопоставлялись с критическими ветками кода. Новые регрессионные сценарии ошибок модерации сначала воспроизводились на прежнем коде. Ранее принятые решения также оценены; полного покрытия всех возможных порядков исполнения это не гарантирует.

## Проверки

На Go 1.27.3:

- Общий `go test -tags stdjson -race -count=1 -skip '^TestLive' ./...` — успешно; после последнего изменения повторены все bot/storage/captcha-тесты.
- `make vet build`, `gofmt -l .`, `git diff --check` — успешно.
- golangci-lint 2.15.0: `config verify`, `make lint` — успешно, 0 issues.
- govulncheck 1.9.0 через `make vuln` — `No vulnerabilities found`; прежний Go 1.26.7 давал предупреждения stdlib.
- Настоящие sh-скрипты проверены тестами: heartbeat и сценарии автодеплоя с подставными командами. Bash/sh syntax check — успешно.
- Кросс-сборка Linux amd64 — успешно. Docker daemon локально не запущен, контейнер не собирался.
- Реквизиты VDS отсутствуют в Git-visible файлах; хранятся только в приватной локальной памяти. SSH и состояние целевого контейнера ранее проверены только чтением.

Не запускались реальные TestLive/Telegram-мутации, продовый деплой/откат, восстановление боевого бэкапа и тест сбоя питания. Временные анализаторы и результаты их работы находятся вне проекта.
