# Что нового

Формат фиксирован: `## vX.Y.Z — YYYY-MM-DD` (длинное тире) и тезисы через
`- `. Файл вшивается в бинарь (`changelog.go`) — из него рендерятся команда
/whatsnew и ЛС-оповещение админам при выходе новой версии, поэтому формат
сторожит тест `TestEmbeddedChangelogParses`.

## v1.13.0 — 2026-08-31
- На сообщении приветствия с требованием ответа появилась кнопка «✅ Впустить (для админов)» — админ может впустить новичка вручную, не дожидаясь его ответа; владельцам с включёнными уведомлениями приходит ЛС «одобрен админом @имя»; кнопка работает всегда, включая эфемерный режим (приветствие публичное)
- После ответа пользователя на приветствие кнопка «Впустить» автоматически снимается — сообщение остаётся в чате без устаревшей клавиатуры
- Обновлён telego до v1.12.1 (миграция API эфемерных сообщений)

## v1.12.0 — 2026-08-24
- Репорт /spam от админа или владельца бота исполняется сразу: без плашки и голосования спамер банится в текущем чате с чисткой сообщений и во всех остальных чатах бота, владельцам уходят форвард улики (до бана) и честный итог; у обычных участников с историей сообщений всё по-прежнему через голосование
- Новая команда /fullunban для админов: снимает баны юзера во всех чатах бота разом, вычёркивает его из глобальной базы спамеров и сбрасывает счётчик проваленных капч везде; как у /unban — список «10 последних забаненных» или сразу @username/реплай

## v1.11.1 — 2026-08-23
- Исправлена эфемерность капчи: при включённом режиме «👻 Эфемерно» вся серия — капча, напоминание и последнее предупреждение — видна только вступившему; раньше публичными уходили напоминания и капча у кого была попытка за последние сутки
- На эфемерных сообщениях кнопка «Впустить» для админов по-прежнему не рисуется (админы их не видят); при выключенной эфемерности серия полностью публичная с кнопкой на каждом сообщении

## v1.11.0 — 2026-08-23
- Капча стала серией из трёх сообщений: капча → через N минут напоминание → ещё через N «ПОСЛЕДНЕЕ ПРЕДУПРЕЖДЕНИЕ» → ещё через N кик. Вся серия — одна попытка: промежуточные таймауты не кикают и не пишутся в статистику, неверный ответ по-прежнему проваливает сразу
- Интервал между сообщениями серии настраивается в минутах: в настройках чата пресеты 1/2/3 мин (по умолчанию 2), глобально — переменная `CAPTCHA_STAGE_MINUTES` вместо `CAPTCHA_TIMEOUT_SECONDS`; сохранённые пер-чатовые таймауты в секундах конвертируются автоматически
- Режим «требовать ответа на приветствие» работает той же серией из трёх сообщений на общем интервале: приветствие → напоминание → последнее предупреждение; отдельная настройка секунд убрана
- Серия переживает рестарт бота: капча и ожидание ответа продолжаются с того сообщения серии, которое было живо; юзер, у которого остались стадии, не наказывается за простой бота

## v1.10.0 — 2026-08-23
- Команда /info в чатах (админская): карточка участника по @username или реплаем на его сообщение/моё приветствие — когда вошёл в чат (или «видимо ранее даты добавления бота» для тех, кто был в чате до меня), сообщения за сегодня/вчера/неделю/месяц/всё время, провалы капчи и молчание после приветствия, подозрения на спам, спам-баны, кики/баны админов, мьюты, флаги «доверенный» и «в глобальной базе спамеров», текущий мьют
- Дата добавления бота в чат запоминается с этого обновления; для чатов, где бот жил раньше, /info показывает приближение по самому раннему событию
- Команда /spam для всех участников с историей сообщений: реплай на сообщение спамера — публичная плашка «Репорт: X считает, что Y — спамер. Забанить?» с голосованием; инициатор и подозреваемый в нём не голосуют, перевес решает, голос админа решает сразу, вердикт банит во всех чатах бота
- Подозрения на спам (плашки ИИ-антиспама, профиль-чека и ручные репорты) теперь сохраняются в истории событий — видны в карточке /info

## v1.9.0 — 2026-08-20
- Подтверждение чатов владельцем: бота добавили в новый чат не владельцы — бот не работает в нём, пока владелец не одобрит в ЛС (кнопки «Да, работать» / «Нет, выйти»); при отказе бот сам выходит из чата и не тратит ни капли активности. Чаты, где бот уже был на момент обновления, работают как раньше, без переспроса
- Владелец может заставить бота выйти из любого своего чата: в «Мои чаты» → чат → настройки → «🚪 Выйти из чата» с подтверждением; при неудаче — кнопка повтора. Админам чата кнопка не показывается
